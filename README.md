# Угадай число двоичным поиском

![Java](https://img.shields.io/badge/Java-007396?logo=openjdk&logoColor=white)

Первая работа курса Java, МГТУ им. Н.Э. Баумана, ИУ1 (февраль 2022).

Пользователь загадывает число от 0 до 2 147 483 647, программа угадывает его двоичным поиском: предлагает середину интервала, а пользователь отвечает `1` — загаданное число меньше, `2` — больше, `0` — угадано. Программа считает число попыток; на весь диапазон `int` хватает 31 вопроса.

## Как запустить

```bash
javac -d out src/com/company/Main.java
java -cp out Main
```
